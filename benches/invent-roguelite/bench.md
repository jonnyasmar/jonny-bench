Invent and build an original roguelite game in Three.js. This is a test of invention, not imitation — do not remake or model the game after any existing title.

Requirements:

- Pure client-side. The finished product must be a static site: an index.html at the repo root (or in dist/ if you use a build step) that works with no server-side code.
- Use Three.js.
- You have full freedom over theme, mechanics, progression, and presentation. Invent something that is fun and addicting.
- Polish counts: game feel, juice, and a loop that makes people want one more run.

You have one shot: when you stop, whatever is in the repo is the submission.
